# Uniquests

Uniquests is a mobile-first web app designed to encourage students to explore their university campus through a location-based treasure hunt game.

## Project Overview

The app allows players to visit campus locations, unlock challenges, answer quiz questions, receive feedback, and track their progress.

## Main Features

- Location-based treasure hunt flow
- Challenge unlocking
- Quiz interaction
- Feedback after answers
- Progress tracking
- Gamification with points, badges, and leaderboard
- Support screens such as Settings and How It Works

## Development Process

The project followed an Agile approach with two main iterations:

- Sprint 1: Core treasure hunt flow
- Sprint 2: Gamification and engagement features
